# Chunduri Kaushik — Portfolio

Personal portfolio of **Chunduri Sai Kaushik**: software engineer working on agentic AI, retrieval systems and data science.

> **All rights reserved.** This repository is public for viewing only. The code, design, artwork, icons, animations, audio and copy may not be copied, reused or redistributed. See [LICENSE](LICENSE).

## What's inside

- Pixel-block loading screen with live load progress
- Particle-built name that reacts to the cursor
- Custom target-lock cursor
- Animated isometric scenes for each project
- A two-sided postcard that visitors can address, save as an image and share
- Responsive layout from small phones to ultra-wide screens, with reduced-motion support

## Structure

```
.
├── index.html              # Page markup
├── assets/
│   ├── css/styles.css      # All custom styles
│   ├── js/main.js          # Interactions, animations, scenes
│   └── audio/              # Ambient soundtrack
├── LICENSE                 # All rights reserved
└── README.md
```

The page is static. Tailwind CSS, three.js and Google Fonts load from CDNs; there is no build step.

## Run locally

```bash
python3 -m http.server 5173
```

Then open http://localhost:5173.
